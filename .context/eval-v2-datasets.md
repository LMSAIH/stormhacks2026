# Eval v2: candidate datasets (surveyed 2026-10-04)

Goal: about 100 short clips of real faces saying natural sentences, with exact transcripts, of people
the lip reader has never seen. The checkpoint (Auto-AVSR `LRS3_V_WER19.1`) was trained on **LRS2,
LRS3, VoxCeleb2 and AVSpeech** (3,448 h), so faces from those sets are not "unseen". GRID is excluded
(command grammar). Everything below was checked live on 2026-10-04; "unverified" marks what wasn't.
The builder is `ml/scripts/build_eval_v2.py`; the clips go only to the private HF dataset
`eschmechel/stormhacks-lipread-eval` (`raw_eval_v2/`, gated sources in their own subfolders).

## Notes
- CREMA-D, RAVDESS: transcripts are the scripted sentences; the builder also runs Whisper on each clip's
  audio and flags any clip whose speech differs from the script (actors sometimes ad-lib).
- Skin tone: only CREMA-D (race) and Casual Conversations (Fitzpatrick) ship labels. For the rest the
  builder measures the Individual Typology Angle (ITA°) on cheek pixels and bins it coarsely; lighting,
  pose (yaw/roll), head movement and face size are measured the same way for every clip.
- A Meta download link is time-limited and specific to the person who accepted. It is not a password,
  but it does let anyone holding it download that file, so it is only used here and not stored.
